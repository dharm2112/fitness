Design a premium, modern mobile app experience for a product called "Squrts".

PRODUCT:
Squrts is an intelligent alarm that uses computer vision and exercise challenges to make users physically get up before their alarm can stop.

Core concept:

Set an alarm
→ Alarm rings
→ Complete the required exercise
→ Computer vision validates the movement
→ Required repetitions completed
→ Alarm automatically stops

The first supported exercise is squats.

Example:
A user sets an alarm for 7:00 AM with a target of 10 squats.

At 7:00 AM:
The alarm starts.
The camera detects the user's body movement.
Squrts validates each squat.
Only valid repetitions are counted.
At 10/10, the alarm stops.

CORE BRAND MESSAGE:

"Your alarm won't stop until you move."

Supporting message:

"Wake up. Move. Start your day."

The product should feel like a real consumer app that could confidently be published on Google Play Store.

--------------------------------------------------
DESIGN DIRECTION
--------------------------------------------------

Create a premium wellness + fitness visual identity.

The design should feel:

- Modern
- Clean
- Energetic
- Friendly
- Motivating
- Human
- Premium
- Approachable
- Technologically intelligent without looking futuristic

Use a warm, bright visual environment rather than an aggressive dark gaming aesthetic.

Avoid:

- Cyberpunk
- Neon
- Gaming UI
- Excessive glow
- Excessive glassmorphism
- Heavy black backgrounds
- Complicated dashboards
- Too many statistics
- Generic bodybuilding aesthetics

Use:
- Strong typography
- Large expressive headlines
- Generous whitespace
- Rounded components
- Soft depth
- Subtle gradients
- High-quality human fitness imagery/illustration
- Clear CTA buttons
- Smooth motion
- Excellent visual hierarchy

Use one distinctive energetic brand accent consistently throughout the experience.

--------------------------------------------------
LANDING / ONBOARDING EXPERIENCE
--------------------------------------------------

Create a long, vertically scrollable landing experience.

The page should feel like a product story rather than a collection of screens.

As the user scrolls:

- elements should animate naturally
- illustrations should subtly move with scroll
- sections should transition smoothly
- numbers and progress indicators can animate
- use subtle parallax
- animations should feel premium and purposeful

Do not overload the page with animation.
